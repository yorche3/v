## 🧪 Convenciones / Conventions

**ES:** Los scripts independientes se ejecutan con `v run` o se compilan con `v`. Los módulos tipo librería usan `v.mod`, separan `src/` y `test/`, y utilizan el framework integrado `v test` + `assert`.

**EN:** Standalone scripts run with `v run` or compile with `v`. Library-style modules use `v.mod`, separate `src/` and `test/`, and use the built-in `v test` + `assert` framework.
